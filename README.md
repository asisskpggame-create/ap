# 💎 Personal Life OS — React Web Edition (v1.5.0)

> **سیستم‌عامل جامع مدیریت مالی، اهداف و مسیر، داشبورد وضعیت و دستیار هوشمند فارسی**  
> بازنویسی کامل به وب‌اپلیکیشن واکنش‌گرا با **React 19**، **TypeScript**، **Tailwind CSS** و **Vite** با حفظ ۱۰۰٪ قواعد کسب‌وکار، مدل‌های داده و طراحی Liquid Glass.

---

## 🌟 قابلیت‌های پیاده‌سازی‌شده در نسخه وب (React)

### ۱. معماری ۴ ستون اصلی با ناوبری شیشه‌ای (Liquid Glass Bottom Bar)
1. **بخش مالی (`DAILY_LOG`)**:
   - ثبت درآمد، هزینه، بدهی، طلب و انتقال بین حسابی
   - انتخابگر چرخشی واحد پول (`تومان`، `هزار تومان`، `میلیون تومان`، `ریال`)
   - مدیریت بدهی و طلب با تسویه پویا و پرداخت جزئی بدون دوباره‌شماری
   - انتقال بین حساب‌های شخصی بدون تغییر در سود/زیان خالص
   - محاسبه خودکار سقف مخارج امن روزانه (`Safe-to-Spend`) با بافر ایمنی ۱۰٪
   - نمودار روند مخارج ۷ روز اخیر

2. **موتور پارسر پیامک بانکی ایران (Bank SMS Parser)**:
   - پردازش ۱۰۰٪ آفلاین و قطعی پیامک بانک‌های ایران:
     - **بانک ملت** (برداشت، واریز، پوز)
     - **بلوبانک سامان** (برداشت، واریز، انتقال)
     - **بانک ملی ایران** (برداشت، واریز، انتقال)
     - **بانک سامان**، **پاسارگاد**، **تجارت**، **سپه**، **صادرات** و **رسالت**
   - فیلتر هوشمند پیامک‌های رمز یکبار مصرف (OTP) و تبلیغاتی
   - تفکیک دقیق مبلغ تراکنش از مانده حساب (`مانده: ...`) و شماره پیگیری
   - تولید اثرانگشت ضدتکرار (Idempotency) برای ممانعت از ثبت تکراری

3. **موتور تشخیص قصد محاوره‌ای فارسی (Transaction Intent Engine)**:
   - تحلیل گرامری بلادرنگ برای جملات فارسی بدون نیاز به هوش مصنوعی ابری:
     - «۲۵۰ هزار تومن اسنپ دادم» ➔ هزینه حمل‌ونقل
     - «از علی ۱ میلیون تومن قرض گرفتم» ➔ بدهی و استقراض
     - «۶۰۰ تومن بابت فروش جمینای گرفتم» ➔ درآمد و فروش
     - «۵ میلیون از کارت اصلی به بلوبانک کارت به کارت کردم» ➔ انتقال حسابی

4. **اهداف، تسک‌ها و عادت‌ها (`GOALS_AND_HABITS`)**:
   - ماتریس آیزنهاور (فوری و مهم، مهم، فوری، عادی)
   - چک‌لیست زیرتسک‌ها (Subtasks)
   - تکرار روزانه، هفتگی و ماهانه
   - پایش عادت‌های روزانه با زنجیره روزهای متوالی (Streaks) و نمایش هفتگی
   - تایمر تمرکز پومودورو شناور (کار عمیق ۲۵ دقیقه / استراحت ۵ دقیقه)
   - ماژول پایش سلامت:
     - کارت موجی مصرف آب (`Water Wave`) با ثبت سریع +۲۵۰ml و +۵۰۰ml
     - پایش ساعات و کیفیت خواب (امتیاز ۱ تا ۵ ستاره)
     - پایش ورزش و فعالیت بدنی (نوع فعالیت، مسافت و زمان)

5. **داشبورد اجرایی (`HOME`)**:
   - کارت اقدام متمرکز بعدی (Next Immediate Action)
   - گیج خرج امن روزانه (Safe-to-Spend)
   - نقشه حرارتی تقویم جلالی با نام ماه‌های شمسی (فروردین تا اسفند)
   - خلاصه‌های سریع وضعیت تندرستی و عادت‌ها

6. **دستیار هوشمند فارسی (`AI_ASSISTANT`)**:
   - شیت صوتی فارسی با تشخیص قصد بلادرنگ
   - الزام تأیید عملیات مالی (`requiresConfirmation`) برای ایمنی کاربر قبل از ذخیره

7. **امنیت و تنظیمات**:
   - قفل گاوصندوق (Vault Lock) با پین‌کد ۴ رقمی
   - پالت‌های رنگی شیشه‌ای (Obsidian Teal, Emerald Matrix, Royal Amethyst, Nordic Frost)
   - پشتیبان‌گیری کامل JSON با بازیابی و بدون حذف داده‌ها (Zero Data Loss)

## 🚀 نحوه اجرا در محیط محلی

```bash
# نصب پکیج‌ها
npm install

# اجرای سرور توسعه (پورت 3000)
npm run dev

# ساخت نسخه پروداکشن
npm run build
```
